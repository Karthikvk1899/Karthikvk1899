## 📈 Featured Projects & Open Source

### 🛡️ [guard-ai-cli](https://github.com/Karthikvk1899/guard-ai)
> **Published PyPI CLI tool (`pip install guard-ai-cli`)** designed to catch AI-generated code vulnerabilities before production.
- **Supply-Chain Guard:** Flags "slopsquatting" (hallucinated PyPI/NPM packages) using an asynchronous SQLite registry cache with 24-hr TTL.
- **Code Linter:** Scans Python, JavaScript, and TypeScript files for hardcoded placeholder API keys and truncated AI output blocks.
- **CI/CD Ready:** Integrates with pre-commit hooks and pipeline fail thresholds (`--fail-on HIGH`, `--json`).

### 📊 [lakeview-cli](https://lnkd.in/eebepXfp)
> **Open-source local dataset diffing & profiling CLI (`pip install lakeview-cli`)** for Parquet, CSV, DuckDB, and Arrow files.
- Identifies schema drift, added/deleted rows, modified records, and shifts in numeric distributions.
- Generates clean Markdown reports tailored for pull requests and CI pipelines without requiring warehouse or notebook overhead.

### ⚡ [diff-lake](https://lnkd.in/eH6YcZpB)
> **In-memory DuckDB dataset comparison tool** built for rapid local ETL and dbt validation.
- Compares 1M+ row files in ~2 seconds with zero cloud dependency.
- Preserves duplicate row counts when unique primary keys are absent, delivering field-level change summaries.

### 📉 [Financial Variance & Anomaly Detection Engine](https://lnkd.in/eupdP-NB)
> **Real-time FP&A and variance reporting platform** ([Live App](https://lnkd.in/eZDQvEj9)) built with Python, DuckDB, Streamlit, and Plotly.
- Implements vectorized Rate/Volume decomposition to isolate Price, Volume, and Mix effects from raw transaction logs.
- Employs dynamic rolling Z-score outlier detection to pinpoint expenditure anomalies while avoiding false alarms.
